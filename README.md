# Sound × Nature — サウンドビジュアライザー

音源をアップロードすると、光・水・オーロラ・樹・星屑・花が音に呼応して姿を変える
ビジュアライザーです。`index.html` を開くだけで動きます（ビルド不要・外部依存なし）。

音声ファイルはブラウザ内だけで処理され、どこにも送信されません。

## 使い方

1. `index.html` をブラウザで開く
2. 「音源を選ぶ」からファイルを指定するか、画面へドラッグ＆ドロップ
   （音源が手元になければ「デモ音源で見る」でその場生成の曲が流れます）

対応形式は MP3 / WAV / M4A / AAC / OGG / FLAC など、ブラウザが再生できるもの。
マイク入力にも対応しています（ハウリング防止のため、マイクの音は出力しません）。

### 操作

| 操作 | 内容 |
| --- | --- |
| スペース | 再生 / 一時停止 |
| 1 〜 6 | シーン切替 |
| ← → | 5 秒シーク |
| F | 全画面 |
| I | 情報パネルの表示 / 非表示 |
| H | UI の表示 / 非表示 |

下部のスライダーで音量・**感度**（音への反応の強さ）・**輝き**（ブルームの量）・
**フィルム**（後処理の強さ）を調整できます。

「自動切替」は押すたびに 15 秒 → 30 秒 → 60 秒 → オフと変わります。指定した間隔を
過ぎると、次の拍に合わせてシーンが移ります（拍が来なければ 5 秒後）。
UI は数秒操作しないと自動的に消え、映像だけが残ります。

> **全画面について** — ページが iframe に埋め込まれている場合、埋め込み側が許可して
> いないとブラウザが全画面を拒否します。そのときは代わりに UI をすべて隠します。
> 本当の全画面にしたいときは、ページを単独のタブで開いてください。

## シーン

| シーン | 内容 |
| --- | --- |
| 光の波紋 | 水平線の光が音に合わせて脈打ち、水面に波紋が広がる |
| オーロラ・ドリフト | オーロラのカーテンが揺らぎ、湖面に映り込む |
| 水の流れ | 流れ場を漂う粒がリボンを描き、ビートで飛沫が跳ねる |
| 光の樹 | 一本の樹が音のエネルギーを浴びて成長し、梢に光が灯る |
| 星屑の軌跡 | 渦巻銀河の星がビートで外へ押し出され、軌道へ戻りながら軌跡を引く |
| 花の呼吸 | 花びらがゆっくり呼吸し、サビで開ききって散る |

## 情報パネル

画面右に、いま鳴っている音楽から読み取った情報を出します（I キーで開閉）。

| 項目 | 内容 |
| --- | --- |
| KEY | 曲のキー（長期のクロマから推定） |
| TEMPO | BPM |
| CHORD | いま鳴っているコードと、直近のコード進行 |
| クロマ | 12 音それぞれのエネルギー。コードの構成音は金色で示します |
| スペクトル | 対数配置の周波数分布 |
| 波形 | 時間領域の波形 |
| 帯域メーター | 低音 / 中音域 / 高音域 / エネルギー |
| シーンの配色 | そのシーンが使っている色 |

## 音と映像の対応

| 帯域 | 表現 |
| --- | --- |
| 低音（ベース・キック） | 波紋、鼓動、大地の明滅、飛沫の勢い |
| 中音域（メロディ・楽器） | 流れ、風、枝のしなり、花びらの開閉 |
| 高音域（ハイハット・シンバル） | 粒子、星、葉のきらめき、花粉 |
| サビ・クライマックス | 光柱、開花、散華、銀河の閃光 |

### 解析のしくみ

- **帯域分割** — FFT（4096点）を 7 帯域に分け、帯域ごとに緩やかに減衰するピーク値で
  正規化します。曲や再生機器による音量差があっても反応の幅が変わりません。
- **ビート検出** — スペクトル流束（前フレームからの増分の総和）が直近の平均を
  一定倍超えた瞬間をオンセットとみなします。閾値は流束の履歴から自動で決まります。
- **曲の起伏** — 市販曲は音圧が詰めてあるため、ピーク比で測ると常に最大値へ張り付いて
  しまいます。そこで直近 20 秒ほどの分布のどこにいるかで測ります。均一に大きい曲は
  真ん中に落ち着き、本当に持ち上がった箇所だけがサビとして出ます。高音の量も
  手がかりに加えています（サビではシンバルや上物が増えるため）。
  静けさ → ビルドアップ → サビ → クライマックスとして各シーンに渡し、
  画面右上に現在の推定を出します。
- **キー / コード** — スペクトルを 12 のピッチクラスに畳み込んだクロマを作り、
  三和音・七の和音のテンプレートと照合してコードを決めます。同じ候補が続いたときだけ
  確定させ、表示のちらつきを防いでいます。キーは長期平均のクロマと
  Krumhansl-Schmuckler のプロファイルとの相関で推定します。
- **テンポ** — オンセット強度を 20ms ごとに貯め、自己相関の山から周期を求めます。
  放物線補間でバケットより細かい値にし、70〜180 BPM に折り返します。

## 実装メモ

単一の HTML ファイルです。Canvas 2D で描画し、加算合成と縮小バッファのぼかしで
ブルーム（後光）をかけたうえに、実写風の後処理を重ねています。

- **後処理** — 光芒（光源を中心に明部を放射状へ引き伸ばす）、アナモルフィックな
  横方向の光条、色収差、黒の浮き、周辺減光、フィルムグレイン。いずれも縮小バッファを
  使い回すので、全画面解像度での処理は最小限です。

- 軌跡が残るシーン（水の流れ・星屑）は、軌跡を専用の透明レイヤに描いてから
  背景や芯の光と合成します。同じバッファに加算し続けると明るさが飽和するためです。
- 発光は放射グラデーションを焼いたスプライトを使い回します。
- フレームレートが落ち続ける環境では、描画解像度を自動的に下げます。

Chrome / Edge / Safari / Firefox の最近のバージョンで動作します。
