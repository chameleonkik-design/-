# Sound × Nature — サウンドビジュアライザー

音源をアップロードすると、光・水・オーロラ・樹・星屑・花が音に呼応して姿を変える
ビジュアライザーです。`index.html` を開くだけで動きます（ビルド不要・外部依存なし）。

音声ファイルはブラウザ内だけで処理され、どこにも送信されません。

## 使い方

1. `index.html` をブラウザで開く
2. 「音源を選ぶ」からファイルを指定するか、画面へドラッグ＆ドロップ
   （音源が手元になければ「デモ音源で見る」でその場生成の曲が流れます）

対応形式は MP3 / WAV / M4A / AAC / OGG / FLAC など、ブラウザが再生できるもの。
マイク入力にも対応しています（ハウリング防止のため、マイクの音は出力しません）。

### 操作

| 操作 | 内容 |
| --- | --- |
| スペース | 再生 / 一時停止 |
| 1 〜 6 | シーン切替 |
| ← → | 5 秒シーク |
| F | 全画面 |
| H | UI の表示 / 非表示 |

下部のスライダーで音量・**感度**（音への反応の強さ）・**輝き**（ブルームの量）を調整できます。
「自動切替」を有効にすると、曲の区切りのよいところでシーンが移り変わります。
UI は数秒操作しないと自動的に消え、映像だけが残ります。

## シーン

| シーン | 内容 |
| --- | --- |
| 光の波紋 | 水平線の光が音に合わせて脈打ち、水面に波紋が広がる |
| オーロラ・ドリフト | オーロラのカーテンが揺らぎ、湖面に映り込む |
| 水の流れ | 流れ場を漂う粒がリボンを描き、ビートで飛沫が跳ねる |
| 光の樹 | 一本の樹が音のエネルギーを浴びて成長し、梢に光が灯る |
| 星屑の軌跡 | 渦巻銀河の星がビートで外へ押し出され、軌道へ戻りながら軌跡を引く |
| 花の呼吸 | 花びらがゆっくり呼吸し、サビで開ききって散る |

## 音と映像の対応

| 帯域 | 表現 |
| --- | --- |
| 低音（ベース・キック） | 波紋、鼓動、大地の明滅、飛沫の勢い |
| 中音域（メロディ・楽器） | 流れ、風、枝のしなり、花びらの開閉 |
| 高音域（ハイハット・シンバル） | 粒子、星、葉のきらめき、花粉 |
| サビ・クライマックス | 光柱、開花、散華、銀河の閃光 |

### 解析のしくみ

- **帯域分割** — FFT（4096点）を 7 帯域に分け、帯域ごとに緩やかに減衰するピーク値で
  正規化します。曲や再生機器による音量差があっても反応の幅が変わりません。
- **ビート検出** — スペクトル流束（前フレームからの増分の総和）が直近の平均を
  一定倍超えた瞬間をオンセットとみなします。閾値は流束の履歴から自動で決まります。
- **曲の起伏** — 立ち上がりが速く戻りが遅い包絡線で「いま盛り上がっているか」を捉え、
  静けさ → ビルドアップ → サビ → クライマックスとして各シーンに渡します。
  画面右上に現在の推定が出ます。

## 実装メモ

単一の HTML ファイルです。Canvas 2D で描画し、加算合成と縮小バッファのぼかしで
ブルーム（後光）をかけています。

- 軌跡が残るシーン（水の流れ・星屑）は、軌跡を専用の透明レイヤに描いてから
  背景や芯の光と合成します。同じバッファに加算し続けると明るさが飽和するためです。
- 発光は放射グラデーションを焼いたスプライトを使い回します。
- フレームレートが落ち続ける環境では、描画解像度を自動的に下げます。

Chrome / Edge / Safari / Firefox の最近のバージョンで動作します。
