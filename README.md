# 『へったのに、ふえた』— Amazon KDP 絵本プロジェクト

> りんごを ひとつ、6人で分けたら、なくなりました。
> ——けれど、そこに種がひとつ残っていました。

幼児向け（2〜5歳・読み聞かせ4分）の絵本一式。
**この世の原理原則を、説明せずに絵の中で起こす**ことを設計方針にしています。

---

## 中心にある原理

> **わけると、へる。でも、ふえる。**

| 原理 | 幼児が受け取るもの | 大人が受け取るもの |
|---|---|---|
| 分けても価値は失われない | はんぶんこは楽しい | 非ゼロサム |
| 減少と増加は同時に起きる | りんごは小さく、仲間は多く | 何を数えるかで世界の見え方が変わる |
| 出し切った先に種が残る | 最後にたねが出てくる | 与えきった場所に次が生まれる |
| 何も起きない時間が要る | 待つとめが出る | 遅延報酬・見えない進捗 |
| 受け取った者が渡す側になる | 最後にまた「はんぶん、こ」 | 循環・恩送り |

## 使い方

```bash
pip install reportlab

# 制作用（仕上がり線・文字セーフエリアのガイド入り）
python3 tools/make_interior_template.py

# 入稿試験用（ガイドなし。KDPプレビューアにそのまま通せる）
python3 tools/make_interior_template.py --clean -o build/interior_clean.pdf
```

出力される寸法（KDPの裁ち落としルールから算出、実行時に表示されます）：

```
ページ数        : 36 (KDP最小24 → OK)
PDFページサイズ : 621 x 630 pt (8.625 x 8.750 in)
仕上がり        : 8.5 x 8.5 in
裁ち落とし      : 3.2 mm (天地=2辺, 小口=1辺, ノド=なし)
300dpi換算      : 2588 x 2625 px
文字セーフ      : 天地小口 15mm / ノド 20mm
```

### このツールが解決している問題

KDPの絵本で最も多い事故は**寸法とノド**です。

- 裁ち落としは**天・地・小口の3辺だけ**に付き、ノド（綴じ側）には付かない
- そのため仕上がり8.5インチ角の位置は**奇数ページと偶数ページで左右が反転する**
- ここを揃えてしまうと、全ページの絵が1ページおきに3.2mmずつずれる

このスクリプトはその反転を織り込んだガイドを描くので、
**イラストが1枚もない段階で**ページ数・綴じ方向・マージン違反を先に潰せます。

## 制作の進め方

1. `docs/02-コンセプト設計.md` と `manuscript/本文原稿.md` を確定する
2. `tools/make_interior_template.py` でテンプレートを出し、**KDPプレビューアに一度通す**
3. `manuscript/作画指示書.md` の「制作順序」に従って作画
   （キャラクターシート → p3の背景 → p33で円環検証 → 繰り返しブロック → 残り → 表紙）
4. `docs/03-KDP入稿仕様.md` の入稿前チェックリストを全項目つぶす
5. **校正刷りを1冊取り寄せて実物を確認する**（プレミアムカラーの発色は画面と違います）
6. Kindle版（固定レイアウト）→ ペーパーバックの順に公開
