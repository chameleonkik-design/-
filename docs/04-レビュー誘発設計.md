# レビュー誘発設計

レビューは「良い本だったから」書かれるのではありません。
**書きたい理由が本の中に仕込まれているとき**に書かれます。

絵本のレビューを書く人の動機は、観察すると次の6つに絞られます。
本作はそれぞれに対して、**具体的なページ**を割り当てています。

---

## 動機① 子どもの反応を報告したい（最強・レビューの過半数）

親は本の感想ではなく、**わが子の変化**を書きます。
「うちの子が◯◯するようになりました」という文型が典型です。

したがって、本は**再現性のある子どもの行動を発生させなければなりません。**

| 仕込み | 発生する行動 | 生まれるレビュー文 |
|---|---|---|
| 「はんぶん、こ！」＋両手で切る動作 | 3回目から一緒に言う／5回目から先に言う | 「読む前に自分で『はんぶんこ！』と言います」 |
| p34の「おやつをはんぶんこ」への誘導 | **現実で分けるようになる** | 「本当にお菓子を半分くれるようになって驚きました」 |
| ふたり→ろくにん の数唱 | 指を折って数える | 「数を数えられるようになりました」 |
| p3とp33の円環構図 | 読み終わると最初に戻る | 「エンドレスになります（笑）」 |

> **p34の一文がこの設計の要です。**
> 「読み終えたら、お子さんと、はんぶん、こ。それがこの本の、ほんとうの最後のページです。」
> これは読者に**宿題**を出しています。宿題を実行した親は、結果を報告したくなります。

## 動機② 自分（大人）が予想外に刺さった

「子ども向けだと思って買ったら、自分が泣いた」——このギャップがレビューを生みます。
商品説明文で**あえて先に予告**しています（「お子さんより、おとなの方が長く考えるかもしれません」）。
予告してあると、刺さったときに「本当にそうだった」と報告したくなります。

| ページ | 大人に効く仕掛け |
|---|---|
| p18-20 「もう こんなに ちいさい／**それでも**、はんぶん、こ！」 | 出し切ることへの覚悟 |
| p25-26 「なにも おきない／つちの なかは、ないしょ」 | 見えない進捗・遅延報酬。**育児中の親に最も刺さる** |
| p23 いちばん小さいピピが種を持っている | 最も少なく受け取った者が次を持つ |
| p31 「ひとつが、いっぱいに なった」 | 非ゼロサム |

> レビューで**引用される一文**を意図的に作っています。
> 引用が発生すると、そのレビューは他の購入者に読まれ、購入を後押しします。
> 引用されやすいのは短く・断定的で・比喩でない文。「つちの なかは、ないしょ。」が第一候補です。

## 動機③ 解釈を語りたい

余白がないと語れません。本作は**説明していない部分**を意図的に残しています。

- p32 の「まだ名前のない小さな動物」は誰なのか（＝読者の分身、と本文は言わない）
- なぜ最も小さいピピのところに種が来たのか
- コロは最初、ひとりで食べるつもりだったのか

これらに答えを書かないことで、レビューが**自分の読み**を語る場になります。

## 動機④ 贈って喜ばれた

ギフト購入者はレビュー率が高い層です。

- 判型を正方形・1,480円にしたのは**単品で贈って成立する見た目と価格**にするため
- 商品説明文に「出産祝い・入園祝い」を明記
- p2に献辞ページ（「わけてくれた ぜんぶの ひとへ」）を置き、**贈る本の顔つき**にしている

## 動機⑤ 個人作家を応援したい

個人出版では「応援」が強い動機になります。
ただし**巻末で露骨にレビューをねだると、絵本の余韻を壊します。**

> **本作の方針：本文中ではレビューを依頼しない。**
> p35の著者紹介の最後に1行だけ、静かに置きます。
>
> ```
> この本が誰かに届いたら、
> 一言でかまいません、感想を残していただけると嬉しいです。
> ```
>
> 「レビュー」という語を使わず、絵本の語り口のまま依頼するのがポイントです。

## 動機⑥ 期待とのギャップ（★★★★★の理由になる）

- **薄さへの不満を先回りする**：36ページは絵本として標準ですが、KDPの自費出版は「薄い」と書かれがちです。商品説明に「読み聞かせ4分」と明記し、**期待値を先に固定**します
- **繰り返しへの不満を先回りする**：「同じ構図の繰り返し」は設計であって手抜きではないことを、p34「おうちのかたへ」で暗に説明しています

## ★1〜2のレビューを潰す

高評価を増やすより、**低評価を出さない**ほうが効きます。KDPの絵本で低評価がつく原因はほぼ3つです。

| 原因 | 対策 |
|---|---|
| **印刷品質**（色が沈む・裁断ズレ） | プレミアムカラー指定。**校正刷りを必ず取り寄せて実物確認**。文字をセーフエリアより内側に |
| **ページが少ないのに高い** | 商品説明で「4分」「36ページ」を先に開示。1,000円未満にはしない |
| **中身が分からず買って外した** | Amazonの「なか見！検索」を有効化し、p3〜p10を公開する |

## 発売直後にレビューを立ち上げる（規約の範囲で）

Amazonのコミュニティガイドラインは、**家族・友人・金銭や物品と引き換えのレビューを禁止**しています。
違反すると出品停止リスクがあります。以下は規約に反しない方法だけを挙げます。

1. **KDPセレクトの無料キャンペーン**（Kindle版）で5日間無料配布し、読者母数を作る
2. **保育園・幼稚園・図書館・読み聞かせボランティアへの献本**
   — 対価としてレビューを要求しないこと。あくまで献本
3. **絵本ナビ等のレビューコミュニティ**に作品登録し、Amazon外のレビューを先に貯める
4. **SNSで制作過程を公開する**（p3とp33が同じ構図であること、パレットが6色であることなどは話題になりやすい）
5. **Kindle版を先行、ペーパーバックを後追い**にして、電子のレビューを紙に引き継ぐ（同一商品ページに統合されます）

> ❌ やってはいけない：家族・知人への依頼、レビュー交換、レビュー対価の提供、
> 献本と引き換えのレビュー要求。いずれもアカウント停止事由です。
