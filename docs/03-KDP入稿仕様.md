# KDP入稿仕様・価格設計

> ⚠️ KDPの料金と選択肢は改定されます。**入稿直前に必ず**
> [印刷コストおよびロイヤリティ計算ツール](https://kdp.amazon.co.jp/ja_JP/help/topic/GSQF43YAMUPFTMSP)
> で実額を再確認してください。本書の数値は2026年8月時点の調査に基づく設計値です。

## 1. 製品仕様（ペーパーバック）

| 項目 | 設定 | 理由 |
|---|---|---|
| 判型 | **8.5 × 8.5 in（21.59cm角）** | 絵本の定番。正方形は書影が目立つ |
| ページ数 | **36ページ** | KDP最小は24p。本作は本編31p＋前後付物5p |
| 綴じ方向 | **左開き・横書き** | 縦書きPDFのフォント埋め込み事故を避ける |
| 裁ち落とし | **あり** | 全ページ全面に絵が入るため必須 |
| インク | **プレミアムカラー** | KDP公式が絵本・児童書に推奨。標準カラーはマット紙で色が沈む |
| 用紙 | 白 | 生成りの地色を使うため、クリーム紙だと色が濁る |
| 表紙仕上げ | 光沢（グロス） | 幼児が触るため。汚れが拭きやすい |

> **標準カラーについて**：2026年4月21日から日本でも選択できるようになりました。
> 1ページ単価が安く（約3.5円 vs 4円）魅力的ですが、
> 用紙がコピー用紙に近いマット紙で、**絵本の赤と緑が明確に沈みます。**
> 本作はプレミアムカラーを指定します。標準カラーは白黒主体の本向けです。

## 2. 寸法の計算

### 本文PDF

```
仕上がり（トリム）  : 8.5 in × 8.5 in
裁ち落とし          : 0.125 in (3.2mm) ／ 天・地・小口の3辺のみ
────────────────────────────────────────
PDFページサイズ     : 幅 8.625 in × 高さ 8.75 in
                      = 621 pt × 630 pt
                      = 2588 px × 2625 px (300dpi)
```

### マージン（KDP必須値）

| 位置 | 最小値 | 本作の設定 |
|---|---|---|
| 内側（ノド） | 9.6mm | **20mm**（文字を置かない） |
| 外側（裁ち落としあり） | 9.6mm | **15mm**（文字を置かない） |
| 天地 | 9.6mm | **15mm**（文字を置かない） |

> 絵は全面（裁ち落としまで）に伸ばし、**文字だけ**を上記の内側に収めます。
> KDPの断裁は個体差があるため、公式最小値ぎりぎりは避けています。

### 表紙

**背幅は自分で計算しないでください。**
ページ数・用紙・インクの組み合わせで変わり、KDPは
[表紙テンプレート生成ツール](https://kdp.amazon.co.jp/ja_JP/help/topic/GYVSFPBRQVWFNRTB)
を提供しています。36ページ／白／プレミアムカラー／8.5×8.5 を入力し、
出力されたPNG/PDFテンプレートの上で表紙を組んでください。

## 3. 価格とロイヤリティ

### ペーパーバック

```
印刷コスト = 固定206円 + (36ページ × 4円) = 350円
```

| 販売価格 | ロイヤリティ60% | 印刷コスト | **1冊あたり手取り** |
|---|---|---|---|
| 1,200円 | 720円 | 350円 | 370円 |
| **1,480円** | 888円 | 350円 | **538円** ← 推奨 |
| 1,650円 | 990円 | 350円 | 640円 |

**推奨：1,480円**

- 国内の同判型絵本の実勢が1,100〜1,650円。1,480円は「ちょっと良い絵本」の位置
- 出産祝い・入園祝いの単品ギフトとして違和感のない価格帯
- 1,000円を切ると「安い自費出版」に見え、**レビューの質が下がります**

### Kindle版（固定レイアウト）

- 固定レイアウトEPUBで作成（リフロー型では絵本になりません）
- 70%ロイヤリティの適用価格帯は **250〜1,250円**
- 70%は**配信コスト（ファイルサイズ×約1円/MB）が差し引かれます**

| 価格 | 方式 | 想定ファイル | 手取り |
|---|---|---|---|
| **980円** | 70% | 約60MB → 配信60円 | **約644円** ← 推奨 |
| 980円 | 35% | 配信コストなし | 343円 |

> 固定レイアウト絵本は画像が重く50〜100MBになりがちです。
> **画像を長辺2000px・JPEG品質85に落として書き出す**ことで配信コストを抑えられます。
> それでも70%のほうが有利ですが、100MBを超える場合は再計算してください。

## 5. 入稿前チェックリスト

- [ ] 全ページ 2588 × 2625 px、CMYK
- [ ] 奇数ページは仕上がり範囲を左寄せ、偶数ページは右寄せ（`tools/make_interior_template.py` のガイドで確認）
- [ ] 文字がノドから20mm、他3辺から15mm以内に入っていない
- [ ] p3 と p33 の背景が完全に一致している（円環の要）
- [ ] 全ページでキャラクターの色と形が一致している
- [ ] りんごの残量が p4→p18 で単調に小さくなっている
- [ ] 人数が p7→p21 で 2,3,4,5,6 と増えている
- [ ] 表紙をサムネイル160px幅に縮小してタイトルが読める
- [ ] 表紙は公式テンプレートの背幅に合っている
- [ ] 総ページ数が36（KDPの最小24以上）
- [ ] KDPのプレビューアで**全36ページ**を目視した
- [ ] 校正刷り（ペーパーバックの著者用コピー）を1冊取り寄せて実物確認した ← **省略しないこと**

## 6. 制作順序（AI画像生成を使う場合）

キャラクターの同一性が最大の難所です。この順で作ると崩れにくくなります。

1. **キャラクターシートを先に作る** — 6匹それぞれ、正面・横・後ろの3ポーズを1枚の画像に。これを全ページの参照画像にする
2. **p3 の背景を完成させる** — 以降の森はすべてこの画像から切り出して使い回す
3. **p33 を p3 の img2img で作る** — 円環が成立するかを最初に検証する
4. 繰り返しブロック（p5〜p16）を**同じシード・同じ構図**で一括生成
5. 単独ページ（p18〜p33）を個別に作り込む
6. 表紙は最後（本文の色調が固まってから）
